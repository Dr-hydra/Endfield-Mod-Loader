# E Mod Loader 使用指南

## Windows

1. 从 [Release](https://github.com/Dr-hydra/Endfield-Mod-Loader/releases/tag/v0.1.0-dev) 下载 Windows ZIP，完整解压到独立目录，运行 `EModLoader.exe`。
2. 点击“导入 ZIP”，选择作者提供的完整模块包。新模块默认停用，确认后开启模块开关。
3. 打开模块页面保存配置；没有网页的模块可使用配置编辑器。
4. 点击“启动游戏”，选择实际游戏可执行文件，等待界面显示游戏宿主连接。

模块网页需要 Microsoft Edge WebView2 Runtime。软件数据默认保存在 `%LOCALAPPDATA%/EndfieldModLoader/`，可通过“打开数据目录”访问。

游戏需要管理员权限时，以相应权限运行 EML。当前版本不自动提升权限；已有 XInput 代理造成加载方式冲突时会报告错误。启动前关闭已有游戏进程。

## Android

需要 Android 10 及以上、ARM64 和支持 libxposed API 102 的兼容框架。

1. 安装 APK，在框架中启用 E Mod Loader，并选择实际使用的终末地客户端作为作用域。
2. 在 EML 应用中导入模块 ZIP，开启模块并保存配置。
3. 彻底停止并重新启动游戏，使框架与原生宿主加载模块。

单独安装 APK 不会启用游戏功能。当前 APK 使用开发签名；框架接入、配置更新和游戏内效果尚未经过设备验证。

## 模块管理

| 操作 | 行为 |
| --- | --- |
| 启用 / 停用 | 开始或结束模块生命周期；停用时请求模块恢复其状态 |
| 配置 / 模块页面 | 保存本模块的 JSON 配置或使用作者提供的网页 |
| 排序 | 调整模块列表顺序；声明的依赖仍决定必要的启动先后 |
| 同 ID 更新 | 安装新代次，保留配置及启用状态；已加载原生库需要重启 |
| 移除 | 移除安装记录；已加载原生代码保留至进程退出 |
| 日志 / 状态 | 查看连接、模块错误、依赖和需要重启的提示 |

模块默认配置只在首次安装时应用。升级时新增配置字段的默认值由模块作者处理。

DLL / SO 不进行热卸载。某些模块需要在后续游戏帧恢复相机、模型等状态；暂停期间的收尾可能要等游戏恢复。

## 离线宿主与游戏宿主

“启动离线宿主”在独立测试进程运行模块，用于检查包、网页、配置与消息通信。离线连接不代表已连接游戏；依赖游戏接口的功能会等待运行时或报告不可用。

Windows 启动游戏时会停止由应用启动的离线宿主。第一人称等游戏功能只能在真实游戏宿主中生效。

## 第一人称

加载器和第一人称模块是独立下载项。导入 `example.first-person-0.1.0-dev.zip` 后启用模块，再在模块页面设置功能。

- Windows 默认使用减号 `-` 切换，要求游戏窗口获得焦点；热键可修改或关闭。
- Android 可保存“默认进入第一人称”；当前没有游戏内触控按钮。
- 默认不切换视角。头部隐藏与颈口填补依赖当前角色骨骼、网格及游戏接口。
- 暂停期间若相机更新停止，退出后的恢复等待后续游戏帧。

参数与构建说明见 [第一人称模块](../examples/first-person/README.md)。

## 常见问题

**网页无法打开：** Windows 检查 WebView2 Runtime；检查模块包是否包含清单指定的 HTML 和本地资源。

**等待游戏运行时：** 离线模式下属于正常状态。游戏中检查框架作用域、游戏宿主连接与模块日志。

**等待依赖：** 安装并启用模块声明的依赖；EML 不自动下载依赖包。

**接口不匹配或加载失败：** 检查模块支持的平台、游戏版本及日志。包格式兼容不代表模块使用的游戏函数兼容。

**更新后提示重启：** 结束当前宿主或游戏，再重新启动。已加载的二进制继续使用原安装代次。
