# E Mod Loader 0.1.3-dev · 新版直接启动适配

Windows 适配新版客户端的官方父进程检查。点击“启动游戏”时，EML 自动寻找并验证官方 `Games.exe`，通过启动桥创建游戏；游戏结束后清理本次桥接进程。请保留官方启动器安装。

- 自动发现支持官方协议、注册表安装项和安装目录，无需手写路径或匹配固定游戏版本字符串。
- 保留按需 UAC、XInput 共存、游戏路径记忆与 DLL 自启动；启动失败时清理本次创建的未完成游戏和父进程。
- 不修改游戏 DLL，不自动安装 XInput 代理；已有 EML 代理避免重复加载 Host。
- 新增可复用的游戏运行时采集与第一人称方法/布局审计脚本，修复桌面测试工程的自包含配置。

已实测 Windows CN 1.6.3 的游戏原始父进程检查通过、EML Host 连通、Echo 收发与运行时辅助接口可用、第一人称初始化为 `ready`。游戏退出码为 0，父进程和启动桥已清理。

Windows 与 Android 示例均编译通过；第一人称 6 组回归通过。Windows 1.6.3 / Android 1.6.4 各有 80 个方法、14 个字段及 20 个布局字段通过静态审计；两个被裁剪的可选 Mesh 接口由既有回退覆盖。启动 59 项、官方启动器 16 项及 Host / XInput / WebView2 回归通过。

**尚未验证：** 第一人称在可操作场景中的视点、输入、切人、头部隐藏、颈口、阴影与恢复；Android 设备上的 EML 运行。新角色祀也尚无专用头饰/局部裁剪规则。初始化成功不等于场景效果验收，完整范围见仓库 `docs/VALIDATION_1_6_3.md`。

下载 `EModLoader-0.1.3-dev-win-x64.zip`，完整解压后运行 `EModLoader.exe`；需要系统 WebView2 Runtime。Android `0.1.0-dev`、第一人称模块 `0.1.0-dev` 附件沿用上一 release 的原文件，SDK ABI 仍为 1、SDK 仍为 `0.1.0`，无需重新导入未变更的模块。SDK 文档同步本轮验证说明。
