# 保留其他 XInput DLL 并加载 EML

从 Windows 0.1.2 起，共存功能是普通版主界面中的正式开关。

1. 确认游戏路径。
2. 勾选游戏路径下方的“保留其他 XInput DLL 并加载 EML”。
3. 点击“启动游戏”。

开关默认关闭。勾选或取消会自动保存到 EML 数据目录的 `launcher.json`，字段为 `allow_xinput_conflict`；下次打开继续使用保存的选择。旧版只有游戏路径的设置仍可读取，共存开关保持关闭。更换游戏路径保留开关选择。

开启后，游戏目录现有的 `xinput1_4.dll` 保持原样，启动器额外向游戏进程加载 EML Host。现有 DLL 按游戏原有逻辑加载。游戏目录没有同名 DLL 时，开关不改变普通启动行为；已有 EML 自己的代理时仍由代理加载 Host，避免重复注入。

“安装 DLL 自启动”和“卸载 DLL 自启动”继续检查文件归属，不覆盖或删除其他工具的 DLL。使用现有加载器共存时，通过 EML 主界面的“启动游戏”加载 EML。

多个工具修改同一处游戏逻辑时仍需验证实际效果。加载或切换原生模块后重新启动游戏，具体模块的接口兼容性见 [兼容性说明](COMPATIBILITY.md)。
